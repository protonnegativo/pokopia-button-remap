# Pokémon Pokopia — Button Icons for Steam Deck, Xbox & PlayStation

**[🇺🇸 English](#-english) · [🇧🇷 Português](#-português)**

---

## 🇺🇸 English

Pokopia shows Nintendo Switch buttons (A, B, X, Y, ZL, ZR, +, −). On a Steam Deck, Xbox or PlayStation
controller the letters sit in different places, so you end up pressing the wrong one.

This mod swaps the icons for **your** controller's: HUD, hints and the title screen, in **every language**.

### Which one to download

Go to **[Releases](../../releases/latest)** and grab the one for your controller:

| File | Controller | Shows |
|---|---|---|
| `Pokopia-Button-Icons-Steam-Deck.zip` | Steam Deck | A B X Y · L1 R1 · L2 R2 · ☰ ⧉ · L3 R3 |
| `Pokopia-Button-Icons-Xbox.zip` | Xbox | A B X Y · LB RB · LT RT · ☰ ⧉ · LS RS |
| `Pokopia-Button-Icons-PlayStation.zip` | PS4 / PS5 | ✕ ○ □ △ · L1 R1 · L2 R2 · Options/Create · L3 R3 |

### How to install

1. **Extract** the zip.
2. In your emulator (Eden, Eglantine or another yuzu-based one), right-click Pokopia >
   **Open Mod Data Location**.
3. **Drop** the mod folder (e.g. `Botoes Steam Deck`) there.
4. In **Properties > Add-ons**, keep the mod **enabled**. Done.

### Good to know

- For game version **2.0.1 / 2.0.1a**.
- Enable **only one** button mod at a time.
- Works **alongside translation mods** such as the PT-BR one. With a translation that ships its own title image,
  only the title screen keeps the Switch button.

## 🇧🇷 Português

O Pokopia mostra os botões do Switch (A, B, X, Y, ZL, ZR, +, −). No Steam Deck, no controle de Xbox ou no
de PlayStation, as letras ficam em outros lugares, e você acaba apertando o botão errado.

Este mod troca os ícones pelos do **seu** controle: no HUD, nas dicas e na tela de título, em **todos os idiomas**.

### Qual baixar

Vá em **[Releases](../../releases/latest)** e baixe o do seu controle:

| Arquivo | Controle | Mostra |
|---|---|---|
| `Pokopia-Button-Icons-Steam-Deck.zip` | Steam Deck | A B X Y · L1 R1 · L2 R2 · ☰ ⧉ · L3 R3 |
| `Pokopia-Button-Icons-Xbox.zip` | Xbox | A B X Y · LB RB · LT RT · ☰ ⧉ · LS RS |
| `Pokopia-Button-Icons-PlayStation.zip` | PS4 / PS5 | ✕ ○ □ △ · L1 R1 · L2 R2 · Options/Create · L3 R3 |

### Como instalar

1. **Extraia** o zip.
2. No emulador (Eden, Eglantine ou outro baseado no yuzu), clique com o botão direito no Pokopia >
   **Abrir local de mods**.
3. **Arraste** a pasta do mod (por exemplo, `Botoes Steam Deck`) para lá.
4. Em **Propriedades > Add-ons**, deixe o mod **ativado**. Pronto.

### Bom saber

- Para o jogo **2.0.1 / 2.0.1a**.
- Ative **só um** mod de botões por vez.
- Funciona **junto com a tradução PT-BR**. Com a tradução ativa, só a tela de título continua com o botão do
  Switch (a imagem de título vem da tradução).
